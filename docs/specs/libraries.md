# Movies and TV Shows

## Purpose
One page per Plex library, with Plex's four tabs.

## Behaviour
- Tab bar at the top: Recommended, Browse, Collections, Categories. A tab opens when focus
  rests on it for 150 ms.
- **Recommended**: Plex's section hubs, ordered Continue Watching, Recently Added, Recently
  Released/Aired, Recently Watched, then the rest. Same accordion rows and info block as Home;
  rows slide up under the tab bar. OK on a Continue Watching item plays it, otherwise opens it.
- **Browse**: all titles in a 7-column grid, sortable by Title, Year, Release date, Date added,
  Rating; pressing the active sort again flips the order. Sorted by title, an A–Z bar on the
  right jumps through the grid.
- **Collections**: Plex collections with the number of titles; OK opens the collection page.
- **Categories**: genre tiles; OK opens a page with that genre's titles.
- Detail page: logo art, facts line, summary, play/resume, seasons and episodes for shows.

## Remote keys
- Down from the tab bar goes to the visible row or the grid.
- Left from the A–Z bar returns to the grid.

## Checks
- Browse A–Z: F → G → H jumps and keeps focus on the bar.
- Down from Collections/Categories tab reaches the first tile.
