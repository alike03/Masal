# Apps

## Purpose
Launch installed TV apps; choose and order the apps shown on Home.

## Behaviour
- Apps page (side menu): "On Home" row with the pinned apps in order, then all apps.
- "Edit Home apps" switches OK from opening to pinning; in that mode OK on a Home app picks
  it up, ◀ ▶ moves it, OK puts it down.
- Outside edit mode play/pause (or Menu) pins or unpins the focused app.
- Pinned apps carry a check mark. The order is stored in settings (`home_apps`).
- Background: one Bing photo of the day for all apps, without any text (no app name, no photo credit).
- "Android settings": the device's settings app, listed like an app (it has no launcher entry on
  TV) so it stays reachable when Masal replaces the stock home screen. Can be pinned to Home.

## Checks
- Pin an app, move it left, see the same order on Home.
